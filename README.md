## 🇬🇧 Overview

Commented Python examples on object-oriented programming: classes and methods, constructors, encapsulation, inheritance, polymorphism and abstract classes.

**Quick start:** `python 01-classes_attributes_methods_functions.py`

## 🇹🇷 Proje hakkında

Python'da nesne yönelimli programlamayı açıklamalı örneklerle anlatan not deposu.

## 📚 İçerik

- `01`: sınıf, nitelik, metot ve fonksiyon
- `02`: `__init__` ile kurucu metot
- `03`: kapsülleme, kalıtım ve çok biçimlilik
- `04`: `abc` ile soyut sınıflar
